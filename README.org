* Overview

This directory contains a curated reference library and a modular suite of *AI Agent Skills* for authoring, running, and publishing computational notebooks, multi-language data analysis pipelines, and literate programming documents using *Emacs Org Mode* and *Org Babel*.

The skills are structured according to the Agent Skills specification (=skills/<skill-name>/SKILL.md=) and can be loaded directly by coding assistants (such as ECA, Claude, and Cursor) or consulted as practical human engineering guides.

* Source Documentation

The documentation in this folder provides exhaustive upstream knowledge drawn from the official Org Mode manual and Worg documentation:

- *[[file:ORGSOURCE.md][ORGSOURCE.md]]*: A condensed, high-yield summary of Chapter 16 of the Org Manual ("Working with Source Code"). Synthesizes block structures, evaluation rules, result handling modes, tangling, Noweb expansion, security settings, and keybindings.
- *[[file:ORGBABEL.md][ORGBABEL.md]]*: The foundational paper / Worg guide /Introducing Babel/ by Eric Schulte, Dan Davison, and Tom Dye. Covers Babel's data path, code blocks as functions, and multi-language interoperability.
- *[[file:ORGMANUAL.md][ORGMANUAL.md]]*: The authoritative reference manual for Org Mode.
- *[[file:R Source Code Blocks in Org Mode.md][R Source Code Blocks in Org Mode.md]]*: Dedicated Worg guide detailing R integration with Org Mode, graphics device parameters, LaTeX export, and interactive debugging via ESS.
- *[[file:Shell Code Blocks in Babel.md][Shell Code Blocks in Babel.md]]*: Dedicated Worg guide detailing shell evaluation across multiple shell binaries, asynchronous background evaluation, and remote system administration.

* Quick Reference: The 5 Concerns of Org Babel

A foundational principle documented in these skills is the five-way separation of concerns:

#+ATTR_LATEX: :align |l|l|p{8cm}|
| Concern | Key Header Arguments | Primary Role |
|---|---|---|
| *Execution* | =:session=, =:eval=, =:dir=, =:var=, =:cache= | Controls whether code executes, in which process, in what directory, and with what inputs. |
| *Results* | =:results= (=value= vs =output=, format, type, handling) | Governs what is captured from execution and how it is formatted into the Org buffer. |
| *Export* | =:exports= (=code=, =results=, =both=, =none=) | Governs what appears in generated human documents (HTML, LaTeX/PDF, Markdown). |
| *Tangling* | =:tangle=, =:shebang=, =:noweb=, =:no-expand= | Governs what source code files are extracted to the filesystem. |
| *Composition* | =:var=, =#+CALL:=, =<<noweb>>=, =org-sbe= | Governs how blocks exchange parameters and pipe results to each other or to tables. |

* Quick Reference: Essential Keybindings

| Keybinding | Command | Context |
|---|---|---|
| =C-c C-c= | =org-babel-execute-src-block= | With point inside a code block: runs the block and updates results. |
| =C-c '= | =org-edit-special= | Opens block in major-mode edit buffer (with LSP & linters); =C-c '= to exit. |
| =C-c C-v b= | =org-babel-execute-buffer= | Runs all code blocks in the notebook buffer sequentially. |
| =C-c C-v s= | =org-babel-execute-subtree= | Runs all code blocks under the current heading. |
| =C-c C-v t= | =org-babel-tangle= | Extracts tangled code blocks into external files on disk. |
| =C-c C-v v= | =org-babel-expand-src-block= | Previews block expansion with all =:var= and noweb substitutions. |
| =M-<down>= / =C-c C-z= | =org-babel-pop-to-session= | Switches focus directly to the interactive REPL buffer for this session. |
| =C-c C-o= | =org-open-at-point= | Opens generated image or linked output file in external viewer or buffer. |
| =C-c C-x C-v= | =org-toggle-inline-images= | Toggles display of inline images in the buffer. |
